# Portfolio-Heatmap

Python、Streamlit、および yfinance API を活用した、**完全無料・コード不要（初期構築後）**で運用できる高機能な米国株投資管理ダッシュボードシステムです。

最新の市場データやドル円為替レートを自動取得し、現金（米ドル・日本円）を含めたアセットアロケーションの確認、主要指数（S&P 500等）とポートフォリオ全体の累積リターン比較、指定期間に連動した株式ヒートマップ分析を一画面でインサイトとして提供します。

---

## 🌟 主な機能

1. **💰 リアルタイム総資産サマリー**
   * 最新のドル円為替レート（`USDJPY=X`）を yfinance から自動取得。
   * 日本円現金を現在のレートで動的にドル換算し、株・ETFと合算した正確な総資産額（ドルベース）をトップに表示。

2. **🟩 期間連動型・5段階ステップヒートマップ（株のみ）**
   * 指定した分析期間（過去1日〜1年、年初来、カレンダーカスタム指定）の総騰落率に応じて、マスの色が5段階で明確に変化。
   * **視認性とアクセシビリティ（カラーユニバーサルデザイン）**に配慮し、下落を「赤」、上昇を「水色（Cyan）」、0%付近の中立を「ダークグレー」で表現。
   * 現金は自動的に除外され、純粋な株式運用のパフォーマンスをマスの大きさ（保有シェア）とともに可視化。

3. **🍕 資産配分（円グラフ・現金含む）**
   * リスク資産（株式・ETF）と安全資産（CASH_USD、CASH_JPY）の本当の比率（アセットアロケーション）をドーナツチャートで可視化。

4. **📈 累積リターン比較推移（折れ線グラフ）**
   * **ポートフォリオ全体の推移表示**: サイドバーのチェックボックスで「現金込（クッション効果を反映したマイルドな波）」と「株式のみ（純粋な運用成果）」を瞬時に切り替え可能。
   * **個別銘柄・ベンチマーク比較**: 保有銘柄の個別表示ON/OFF、および主要指数（S&P 500、NASDAQ 100、日経225、TOPIX）との累積リターン比較。
   * **超短期・分足対応**: 過去1日（5分足）、過去3日〜1週間（15分足）のデータを自動適用し、短期のトレンドもカクカクせず滑らかに描画。
   * **カスタム期間指定**: カレンダーから任意の開始日・終了日を選択して、その期間を基準（0%）としたリターンを再計算可能。

## 📁 フォルダ・ファイル構造

本システムを配置するフォルダ内に、以下の3つのファイルを設置します。

```text
portfolio_dashboard/
 ├── app.py              # アプリケーション本体（Pythonプログラムコード）
 ├── portfolio.csv       # 保有資産の設定ファイル（ユーザーが作成・編集）
 └── requirements.txt    # 依存ライブラリの環境設定メモ
```

## 🚀 セットアップと実行手順

### 1. 必要な環境のインストール
コマンドプロンプトまたはターミナルを開き、以下のコマンドを順番に実行してライブラリを強制クリーンインストールします（Numpy2.0系の互換性エラー対策済）。

```bash
# 依存ライブラリをキャッシュを無視して強制インストール
pip install --force-reinstall --no-cache-dir "numpy<2" pandas yfinance plotly streamlit
```

### 2. 保有資産データの作成 (`portfolio.csv`)
`app.py` と同じフォルダに `portfolio.csv` を作成し、ご自身の現在の保有資産を入力します。

```csv
Ticker,Shares
AAPL,10
MSFT,5
NVDA,15
CASH_USD,5000
CASH_JPY,1500000
```
* **株式・ETF**: `Ticker` に米国市場の記号（大文字）、`Shares` に保有株数を入力。
* **米ドル現金**: `Ticker` を `CASH_USD` とし、`Shares` にドル金額を入力。
* **日本円現金**: `Ticker` を `CASH_JPY` とし、`Shares` に円金額を入力（システムが自動で最新レート換算します）。

### 3. ダッシュボードの起動
フォルダに移動し、Streamlitを起動します。

```bash
python -m streamlit run app.py
```
* 初回起動時のみ、黒い画面に `Email:` という案内が出ます。**何も入力せずにそのまま「Enterキー」を押してください。**
* 自動的にブラウザが立ち上がり、ダッシュボード（`http://localhost:8501`）が表示されます。

## 🛠️ トラブルシューティング

### `ValueError: numpy.dtype size changed...` と表示される場合
裏方の計算ライブラリのバージョンが競合しています。一度Streamlitを閉じ（Ctrl + C）、手順1の `--force-reinstall --no-cache-dir "numpy<2"` が含まれるインストールコマンドを再実行してください。
